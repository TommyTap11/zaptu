# Agent notes

Brand: Zaptu (zaptu.ai). This repo is vertical 1 — the home-services lead router.

- Tools live in `src/aslc/server.py`.
- Shared pipeline is `src/aslc/service.py` — REST, MCP, and any future widget must stay on the same function.
- Add a new trade by extending `ServiceType` and `SUPPORTED_SERVICES`.
- Add a buyer by implementing `Forwarder` in `src/aslc/forwarding.py`.
- Do not tell the end user a specific company is booked. This product sells a lead/call.
- Never drop `consent_to_contact`.
- Do not hold user OAuth tokens in this phase.
- Agent-facing metadata (service catalog, OpenAPI, server cards, mcp.json) lives in `src/aslc/catalog.py`.
  After changing tools or catalog, run `python3 scripts/build_discovery.py` (static copies in `web/`); tests fail on drift.
- Site regeneration: `python3 scripts/build_plumbing_cities.py && python3 scripts/build_service_cities.py && python3 scripts/seo.py`
  (in that order: the plumbing script rewrites the tail of llms.txt). `seo.py` owns the shared
  header nav, footer links (incl. Contact mailto:hello@zaptu.ai), and icon/manifest tags on every page.
- Every service, plumbing included, goes through the same /v1/intake form and requires `consent_to_contact=true`
  (Polyares consent wording). The Client Connector call-to-connect number was dropped on 2026-10-26; do not re-add it.
- Since 2026-11-02 cleaning, pest-control and plumbing pages show the Polyares hosted form (iframe, category 24/37/1)
  first, with the /v1/intake form (+ Netlify Forms backup) collapsed below as a fallback. Generated by cta_html();
  `scripts/apply_polyares_forms.py` patches existing pages in place without touching frozen copy.
- Plumbing pages (hub + cities) also show the Polyares plumbing tracking number 855-360-1813 (tel:+18553601813)
  in the Polyares block (`POLYARES_PLUMBING_PHONE`, issued 2026-11-02). Plumbing only: never on other categories.
