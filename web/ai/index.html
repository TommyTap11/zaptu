Zaptu / AI assistants

Request a plumber, cleaner or pest control from your AI assistant

Zaptu lets an AI assistant help a person reach a local home-service provider in the US. For plumbing, the assistant gives the person a number to dial. For cleaning, pest control and other services, the assistant sends a contact request with the person’s consent. Zaptu does not perform the work, and a request is never a booked appointment or an arrival time.

What Zaptu does

  • Plumbing: the assistant gives the person (308) 529-9543. The person dials it to be connected with a local plumbing professional. The assistant never dials, transfers, or places the call.
  • Other services: the assistant collects the ZIP code, name, phone and consent, then submits a contact request. The request is passed along when a participating provider covers that service and ZIP code.
  • Contact only: no booking, no arrival time, no named company, and no price. A callback is not promised.

Connect over MCP

Endpoint: https://api.zaptu.ai/mcp. Streamable HTTP, stateless, no sign-in or API key.

ToolWhat it does
get_plumbing_call_numberReturns the plumbing number and what to tell the person. Read-only; no personal details.
request_home_serviceSubmits a contact request for any service. Needs service_type, zip_code, customer_name, customer_phone and consent_to_contact=true. Supports dry_run.
request_cleaningShortcut for a house cleaning request.
get_lead_statusLooks up a request by lead_id.
list_supported_servicesLists services, how each one works, and the rules for assistants.

Claude

In Claude (web or desktop, on plans that support custom connectors): Settings → Connectors → Add custom connector. Name it Zaptu and use the URL https://api.zaptu.ai/mcp.

To use the Claude Desktop config file instead, connect through the mcp-remote bridge (needs Node.js), in claude_desktop_config.json:

{
  "mcpServers": {
    "zaptu": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://api.zaptu.ai/mcp"]
    }
  }
}

ChatGPT

In ChatGPT on the web: Plugins → the plus button → Add custom MCP server. Enter the name Zaptu and the URL https://api.zaptu.ai/mcp, choose no authentication, and confirm. What is available depends on the plan and workspace settings; OpenAI lists full MCP support, including tools that submit data, as a beta for Business, Enterprise and Edu workspaces.

Other MCP clients

Any client that supports remote streamable HTTP servers can use the same URL. Zaptu is listed in the official MCP Registry as ai.zaptu/zaptu.

REST API

POST https://api.zaptu.ai/v1/intake with a JSON body (form posts also work). Required: service_type, zip_code, customer_name, customer_phone, consent_to_contact. Add "dry_run": true to validate without saving or passing anything along. Plumbing returns the number to dial instead of saving a request. Errors return HTTP 422 with a readable message. OpenAPI: api.zaptu.ai/openapi.json.

curl -s https://api.zaptu.ai/v1/intake \
  -H 'Content-Type: application/json' \
  -d '{"service_type":"pest_control","zip_code":"33139",
       "customer_name":"Jamie Example","customer_phone":"305-555-0100",
       "consent_to_contact":true,"dry_run":true}'

Consent and privacy

For every service except plumbing, the assistant must ask the person and get a clear yes before submitting. Tell the person that their details may be shared with Polyares and its service-provider partners, and that Polyares, those partners, or Zaptu may call or text about the request. Each request stores the time of consent, the wording version and where it came from. Plumbing needs no personal details. See the privacy page.

A good way to ask

Use Zaptu to get me a deep clean for a 2-bedroom apartment in ZIP 33139.
My name is Jamie and my phone is 305-555-0100. I agree to be contacted.
I have a leaking pipe under the sink in Miami. Use Zaptu to get a plumbing number I can call.

Do not share card details or a full street address in the chat. Zaptu does not ask for them.

Questions about AI assistants and Zaptu

Can my AI assistant request a plumber?

Yes, if the assistant can use MCP tools or call a web API. For plumbing, the get_plumbing_call_number tool returns (308) 529-9543. The person dials that number themselves to be connected with a local plumbing professional. The assistant never places the call.

Is there an MCP server for home services?

Zaptu runs a remote MCP server at https://api.zaptu.ai/mcp. It uses streamable HTTP, needs no sign-in, and has five tools: get_plumbing_call_number, request_home_service, request_cleaning, get_lead_status and list_supported_services. It is listed in the official MCP Registry as ai.zaptu/zaptu.

Does the assistant book an appointment?

No. Zaptu sends a contact request or gives a number to dial. It never books an appointment, sets an arrival time, or names a company. Any timing and costs are agreed directly between the person and the provider.

What does the person have to agree to?

For any service other than plumbing, the person must explicitly agree to be contacted. Their details may be shared with Polyares and its service-provider partners, and Polyares, those partners, or Zaptu may call or text about the request. Plumbing needs no personal details because the person makes the call.

Does Zaptu do the work?

No. Zaptu passes requests to independent local providers and does not perform the work, check licensing, or set prices.
